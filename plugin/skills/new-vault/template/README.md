# <VaultName>

A learning vault built with the `engram-study` Claude Code plugin. Open this folder in Obsidian;
run the commands from Claude Code in this folder. Start with `GUIDE.md`. Agent rules: `CLAUDE.md`.
Settings (owner, personal or work, git, Anki): `vault.json`.

## Folders
- `concepts/`: one concept per note, in your own words (knowledge layer)
- `maps/`: study paths, concepts in prerequisite order
- `sources/`: what you learned from: videos, papers, docs, repos, specs (reference layer)
- `projects/`: work and personal reference
- `log/`: one file per day of what was captured, connected, carded and recalled
- `templates/`: note templates
